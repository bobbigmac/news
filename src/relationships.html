Source & Story Relationships

The source bar is not a literal list of every host. This page exposes the curated relations behind the convenience groups, the current allocated branches, and the subject tree used by optional tag grouping.

How to read this

Relation ≠ claim

A branch can mean shared owner, public-service model, specialist beat, regional market, wire pipe, platform, or another useful property. The full memberships are listed because one host can reasonably belong to more than one relation.

Rendered branches are disjoint

The underlying graph can overlap, but the UI claims each host once in tree order. That prevents duplicated controls while still documenting every relation here.

Sizes are article-driven

The allocator chooses the branch depth that lands near a readable number of stories. Tiny branches roll up; very large atomic outlets can remain single controls.

Profiles are research notes

Profiles use different fields because the useful properties are different: ownership, funding, remit, political context, provenance risk, shared journalists, distribution model, or notable history.
